## Utvalda projekt

### Davar SmartScan

En pågående skanningsfunktion som extraherar text från tryckta sidor och identifierar relevanta nyckelord. Lösningen använder separata modeller, tjänster och controllerlogik för att vara enkel att vidareutveckla.

**Teknik:** Flutter, Dart, OCR och API-integration

- OCR-baserad textextraktion från tryckta sidor.
- Identifiering och bearbetning av relevanta nyckelord.
- Tydlig uppdelning mellan modeller, tjänster och controllers.

### Realtidsplattform för quiz

En fullstackplattform där en Flutter-klient kommunicerar med en Laravel-backend genom REST och WebSockets. Realtidsflödet synkroniserar frågor, svar och resultat mellan användare.

**Teknik:** Laravel, Flutter, REST API, WebSockets, MariaDB och GitHub Actions

- Implementerade REST-kommunikation mellan mobilklient och backend.
- Integrerade WebSockets för synkronisering i realtid.
- Arbetade med MariaDB, Linuxserver och webbdeployment.
- Byggde ett CI/CD-flöde för automatisk build och deployment av Flutter Web.

### Noog API

Ett fullstackbaserat grupprojekt där ett strukturerat .NET-API möter en React-klient. Projektet fokuserar på validerade dataflöden och en tydlig separation mellan frontend och backend.

**Teknik:** .NET Core, React, Entity Framework, SQL Server och Azure DevOps

- Repository pattern och tydligt separerade ansvarsområden.
- Validering och strukturerad datahantering.
- Samarbete och versionshantering genom Azure DevOps.

### Clean Architecture vs Vertical Slice Architecture

Ett examensarbete där två funktionellt likvärdiga, CRUD-baserade Web API-prototyper utvecklades och jämfördes. Studien utvärderade arkitekturerna utifrån utvecklingshastighet, kodstruktur, testbarhet och overhead.

**Teknik:** .NET 10, ASP.NET Core, Entity Framework Core och testning

- Implementerade samma funktionalitet med två olika arkitekturer.
- Jämförde praktiska skillnader i struktur, testbarhet och utvecklingsflöde.
- Dokumenterade avvägningar mellan långsiktig struktur och initial komplexitet.

## Om portfolion

Den här webbplatsen är byggd som en snabb och responsiv single-page portfolio med ett mörkt och ljust tema, tillgänglig navigation och ett komponentbaserat upplägg.

**Stack:** React 19, TypeScript, Vite, Tailwind CSS och vanlig CSS.

### Kör projektet lokalt

```bash
git clone https://github.com/ikariLain/Portfolio.git
cd Portfolio
npm install
npm run dev
```

### Tillgängliga kommandon

| Kommando | Beskrivning |
| --- | --- |
| `npm run dev` | Startar den lokala utvecklingsservern |
| `npm run build` | TypeScript-kontroll och produktionsbuild |
| `npm run lint` | Kontrollerar kodkvalitet med ESLint |
| `npm run preview` | Förhandsvisar produktionsbuilden lokalt |
